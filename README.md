# The Office

O **The Office** é um site de vendas desenvolvido utilizando **JavaScript, Express, PostgreSQL e EJS**. O projeto tem como objetivo oferecer uma plataforma para a visualização e comercialização de produtos, integrando o back-end ao banco de dados e utilizando templates dinâmicos para a construção das páginas.

## Tecnologias utilizadas

- **JavaScript** — lógica e funcionalidades do sistema.
- **Express** — gerenciamento de rotas e requisições.
- **PostgreSQL** — armazenamento e gerenciamento dos dados.
- **EJS** — criação de páginas dinâmicas.
